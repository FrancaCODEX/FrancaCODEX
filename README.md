## 🎮 Projeto em destaque — CritPlay

**Uma comunidade de jogos inspirada em plataformas de avaliação e descoberta de conteúdo.**

O CritPlay é uma aplicação web desenvolvida com Java e Spring Boot, que permite aos usuários explorar jogos, registrar experiências, publicar avaliações e interagir com outros jogadores.

**Principais funcionalidades:**
- Catálogo de jogos com buscas, filtros e importação de dados externos.
- Avaliações, resenhas, favoritos e listas personalizadas.
- Cadastro, autenticação, perfis e gerenciamento de usuários.
- Integrações com APIs externas, incluindo RAWG e GG.deals.
- Persistência relacional, migrações de banco de dados e gerenciamento de permissões.
- Testes automatizados e integração contínua com GitHub Actions.

**Stack:** Java 17, Spring Boot, Spring Security, Spring Data JPA, PostgreSQL, H2, Flyway e Maven.
